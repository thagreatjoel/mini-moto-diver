# Features
- 4 Channel low side Switching
- High current capability
- Logic level controlling
- Flyback proctection
- Low power comsumption 
- Status indicator 


## Applications
- Mini robotics projects
- dc motor control
- LED control systems
- IoT automation
- ESP32/Raspberry Pi projects
- Mini drones
